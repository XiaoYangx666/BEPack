# BEGame starter

This project contains a BEPack-managed behavior pack and resource pack. The behavior pack includes a small `@minecraft/server` example that welcomes players on their first spawn.

Run `npm run build` to build the packs, or `npm run dev` to copy them into the Minecraft development folder on Windows. On macOS and Linux, configure a copy target in `bepack.config.ts` before using `bepack dev --copy`.
